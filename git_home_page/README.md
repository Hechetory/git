# Xiaobo Feng — Academic Homepage

A small, data-driven academic homepage built with Jekyll for GitHub Pages.
The visual design lives in templates and CSS; frequently changed academic
content lives in YAML and Markdown files.

See [MAINTENANCE.md](MAINTENANCE.md) for everyday editing, preview, and Git
instructions.

## Content map

- Personal profile: `_data/profile.yml`
- Education: `_data/education.yml`
- Research interests: `_data/research.yml`
- CV metadata: `_data/cv.yml`
- Notes: one Markdown file per item in `_notes/`
- Publications: one Markdown file per item in `_publications/`
- Talks: one Markdown file per item in `_talks/`
- PDFs and slides: `assets/pdfs/`

## Why Jekyll

Jekyll is supported directly by GitHub Pages, needs no database or server-side
application, and turns simple YAML/Markdown content into a static site. This
makes it a stable fit for a small academic homepage that will be edited on
GitHub over a long period.
